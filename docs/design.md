# 拾光笔记设计与实现方案

用户已确认简洁技术博客、本地 Markdown 文章。目标路径为 D:\Projects\personal-blog；当前环境写入 D 盘失败，先在临时工作区验证，并提供可解压到非 C 盘的压缩包。

## 页面

首页展示精选文章、分类筛选、分页文章列表和作者信息。分类页包含分类及标签计数，并通过 URL 筛选首页文章。归档按年月整理文章。关于页介绍作者和常用工具。文章详情支持代码高亮、目录、阅读进度、复制链接及相邻文章。全局支持搜索、深浅主题、移动菜单、返回顶部及 404。

## 结构

Vue 3 + TypeScript + Vite + Vue Router + Element Plus。文章采用 YAML 头信息和 Markdown 正文；yaml、markdown-it 与 DOMPurify 分别处理元数据、渲染及 HTML 清理。关闭原始 HTML，highlight.js 按需注册 JavaScript、TypeScript、CSS 和 JSON。Element Plus 使用按需组件导入。封面保存于 public/images。作者与品牌在 src/config.ts 配置。

## 视觉

白色与浅灰绿背景，石墨文字、森林绿主色，少量黄色及赤陶色点缀。首页左右分栏，文章列表提供真实封面和阅读信息。宋体展示中文品牌和标题，无衬线字体用于正文及导航。卡片圆角不超过 8px，文章侧栏采用留白和分隔线。移动端单栏布局，320px 起无横向溢出。

## 状态和容错

分类、标签和分页保存在 URL。主题保存在 localStorage，存储受限时降级到当前会话。搜索覆盖标题、摘要、标签和正文。空搜索结果提供清空入口，文章不存在时显示返回首页。日期按 UTC 解析。路由采用 hash 模式，部署静态空间时无需配置 SPA 重写。
